## Featured Projects

### Sunna3 — Maintenance Management Platform
> *Full-stack platform connecting tenants with qualified maintenance vendors through a structured, transparent workflow*

The idea behind Sunna3 came from a simple frustration: finding a trustworthy technician is harder than it should be. Sunna3 solves this with a complete end-to-end maintenance workflow — tenants raise tickets, vendors apply, managers oversee, and everything from job execution to payment happens inside the platform.

**What makes it more than a CRUD app:**
- **AI-assisted ticket creation** — guides tenants before submitting to reduce unnecessary requests
- **Predictive maintenance alerts** — AI models flag devices likely to need attention based on history
- **Real-time analytics dashboard** — charts and reports giving actual visibility into platform activity
- **Multi-step approval workflow** — tenant selects vendor from applicants, manager supervises, status tracked live
- **Secure online payment** — processed directly through the platform post-job-completion
- **Role-based architecture** — Tenant, Manager, and Vendor each have isolated, dedicated flows

**Stack:** .NET · Angular · EF Core · SQL Server · SignalR · Clean Architecture · AI Models

### TeleChat — Real-Time Communication App
> *Beyond basic messaging — a full communication suite built on SignalR and WebRTC*

Most .NET chat demos stop at text messages. TeleChat goes further. Built with Angular and .NET, it brings together the features that real communication apps offer:

- **Live video calls** — camera-to-camera with real-time stream handling
- **Voice-only calls** — clean audio sessions without video overhead
- **Call recording** — sessions can be captured so conversations aren't lost
- **Real-time messaging** — instant bidirectional delivery via SignalR over WebSockets
- The Angular frontend manages live connection state as calls open and close; the .NET backend handles hub connections, call signaling, and session management with typed TypeScript integration

**Stack:** .NET · SignalR · Angular · TypeScript · WebRTC · WebSockets

### Questar — Online Exam & Certification Platform
> *Automating the full testing lifecycle — from live exam sessions to instant certificates*

Building a reliable online exam system is harder than it looks. You need strict session control, fair auto-grading, tamper-resistant results, and a smooth experience — all at once. Questar handles all of it:

- **Live exam sessions** — enforced time limits, real-time countdown, controlled submission flow
- **Instant auto-grading** — results calculated the moment a candidate submits, no manual review needed
- **Detailed result breakdowns** — candidates see exactly where they performed well and where they didn't
- **Automatic certificate issuance** — passing candidates receive a certificate generated by the system immediately
- **Admin dashboard** — manage question banks, configure pass thresholds, track all candidates in one place

**Stack:** .NET · ASP.NET Core · EF Core · SQL Server
